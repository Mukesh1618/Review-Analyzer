# ReviewMind: Product Reviews Analyzer & Q&A (Agentic AI)

An AI-powered application that analyzes product reviews and enables users to interact with them via conversational Q&A using a multi-agent system built with LangChain.

## Project Structure (Aligned with Specifications)

- **backend/**: FastAPI server, LangChain agents, and business logic.
- **frontend/**: React (Vite) application for the user interface.
- **data/**: Storage for FAISS vector indices and sample review files.
- **development_assets/**: Legacy code, debug scripts, and documentation assets.
