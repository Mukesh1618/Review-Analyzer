                                 USER & ARCHITECTURE GUIDE

Welcome to ReviewMind! This comprehensive guide provides an overview of the platform,
its user interface pages, technical features, vector storage engine, the multi-agent
orchestration pipeline, and complete instructions on running the application locally.

--------------------------------------------------------------------------------
1. PRODUCT OVERVIEW & WHAT THE WEBSITE DOES
--------------------------------------------------------------------------------
ReviewMind is an enterprise-grade, dark-themed AI platform designed to transform
unstructured customer feedback into structured, actionable business intelligence. 
By employing a collaborative Multi-Agent system powered by LangChain and LangGraph, 
ReviewMind parses, validates, aggregates, and visualizes thousands of customer reviews
in seconds. It eliminates the manual work of reading reviews, automatically tracking
sentiment trends over time, highlighting aspect-specific performance, auditing review
authenticity, and exporting executive-ready PDF documents.

--------------------------------------------------------------------------------
2. COMPREHENSIVE PAGE-BY-PAGE FEATURE WALKTHROUGH
--------------------------------------------------------------------------------

ReviewMind features a responsive sidebar navigation that guides users through a
cohesive, dark-themed experience with premium glassmorphic UI elements.

[A] LANDING & LOGIN PAGE
- Sleek corporate portal introducing the platform's core capabilities.
- Provides secure user authentication allowing customized, secure review indexing
  and profile management.

[B] KNOWLEDGE INGESTION (UPLOAD PAGE)
- **Multi-Format Ingestion:** Supports uploading custom review datasets in CSV,
  JSON, or plain text (.txt) formats.
- **Sample Datasets:** Allows immediate testing using high-quality preloaded datasets:
  * ZenithBook Pro 14 Laptop Reviews (50 detailed reviews)
  * ApexPhone Pro Smartphone Reviews (100 detailed reviews)
- **AI Gatekeeper Agent:** The uploaded file is passed through a validation node.
  The LLM acts as a gatekeeper, analyzing sample contents to ensure it consists of
  legitimate reviews and customer feedback. If random code, server logs, or garbage
  text is uploaded, the agent rejects it with a specific explanation.
- **FAISS Vectorization:** Once validated, the reviews are split into chunks, converted
  into 384-dimensional dense vectors using HuggingFace embeddings (`all-MiniLM-L6-v2`),
  and indexed into a local FAISS (Facebook AI Similarity Search) database.

[C] INSIGHTS DASHBOARD
- **Core Bento Metrics Grid:** Displays key high-level statistics:
  * **Total Reviews:** Total number of verified, ingested feedback points.
  * **Sentiment Score:** Overall AI-calculated product score on a 1-10 scale.
  * **Top Keywords Mentioned:** Commas-separated list of the 5 most discussed keywords,
    rendered as styled visual tags (e.g., #OLED screen, #premium build).
- **Sentiment Distribution Donut Chart:** Visualizes the exact proportion of
  Positive, Neutral, and Negative reviews in an interactive circular chart.
- **Interactive Sentiment Trend Graph:** An SVG-based chronological timeline plotting 
  average sentiment score by date. Hovering over any individual square marker reveals
  an interactive tooltip showing the precise date and recorded score.
- **AI Executive Summary Card:** Summarizes the core product recommendation alongside
  three key highlighted metric panels:
  * *Key Strength* (biggest product asset)
  * *Top Complaint* (biggest bottleneck or defect)
  * *Emerging Request* (the most requested feature update)
- **Raw Review Samples Log:** A searchable tabular log showing verified review snippets,
  their individual sentiments (Positive, Neutral, Negative), and dates.

[D] DEEP-DIVE ANALYSIS PAGE
- **I. Executive Summary & Product Synthesis:** An in-depth overview of the overall product
  reception, compiling all feedback into a professional business synthesis.
- **II. Strengths & Weaknesses Panel:** Side-by-side bento cards displaying a vertical layout
  of key pros (soft-green panel) and cons (soft-red panel) for quick review.
- **III. Aspect Attribute Scorecard:** A structured matrix that extracts primary features
  (e.g., Battery, Performance, Display, Price) and rates them on a 1-10 scale. Each score is
  categorized into a color-coded benchmark badge:
  * **EXCELLENT** (Green tags for scores >= 8.0)
  * **GOOD** (Orange tags for scores >= 6.0)
  * **CRITICAL** (Red tags for scores < 6.0)
- **IV. Review Authenticity Audit:** A dedicated pink audit container displaying an integrity
  trust score and identifying bot patterns, repetitive spam templates, and suspicious reviews.
- **Download Report Button:** Instantly generates and compiles a professional PDF report.

[E] CONVERSATIONAL CHAT INTERFACE
- **Evidence-Based Q&A:** A conversational window where you can ask specific questions
  about the product (e.g., "Is the screen bright enough?").
- **Semantic RAG Retrieval:** The system query is converted to vector embeddings, retrieves the
  closest relevant review snippets from the FAISS database, and presents an evidence-backed
  answer complete with source reviewer citations.

3. TECHNICAL MULTI-AGENT ARCHITECTURE (LANGGRAPH)
--------------------------------------------------------------------------------
ReviewMind utilizes a stateful LangGraph workflow to coordinate 5 specialized, parallel
AI agents to analyze the ingested data:

1. **Identity Agent:** Extracts the target product name and predicts a 1-5 star rating.
2. **Descriptive Agent:** Parses the reviews using boundary-restricted regexes and fallbacks
   to extract the Short Summary, Detailed Summary, Pros, Cons, and Key Metrics.
3. **Scoring Agent:** Computes the true sentiment (Positive, Neutral, Negative) across all
   reviews in batches and scores specific aspect qualities.
4. **Timeline Agent:** Batches reviews chronologically to map scores against dates.
5. **Security Agent:** Conducts spam checks and evaluates text repetition for review integrity.

5. HOW TO RUN THE PROJECT LOCALLY
--------------------------------------------------------------------------------

Follow these simple steps to spin up the application on Windows:

[A] PREREQUISITES
- Node.js (v18+) & npm installed.
- Python 3.10+ installed.
- A `.env` file created in the project root containing your LLM API Keys (e.g., `GROQ_API_KEY=your_key_here`).

[B] STEP 1: RUN THE FastAPI BACKEND
1. Open Windows PowerShell or Command Prompt in the project root (`c:\Work\Review-Analyzer`).
2. Activate the virtual environment and start the Uvicorn server:
   ```powershell
   .\venv\Scripts\python.exe -m uvicorn backend.main:app --port 8000 --reload
   ```
3. The backend is running once you see: `Uvicorn running on http://127.0.0.1:8000`

[C] STEP 2: RUN THE REACT FRONTEND
1. Open a second PowerShell terminal in the project root.
2. Navigate into the frontend folder:
   ```powershell
   cd frontend
   ```
3. (First time only) Install frontend node modules:
   ```powershell
   npm install
   ```
4. Start the Vite development server:
   ```powershell
   npm run dev
   ```
5. Open your web browser and navigate to the address shown: `http://localhost:5173`

--------------------------------------------------------------------------------
6. CACHE & PERSISTENCE ENGINE
--------------------------------------------------------------------------------
- **Instant Reloads:** To avoid redundant, costly LLM calls, analysis results are
  persisted as `analysis.json` inside each product's FAISS directory:
  `data/faiss_index/[user_id]/[product_name]/analysis.json`
- **Bypass Safeguards:** The frontend incorporates cache invalidator routines. If an analysis
  is corrupted or yields "Analysis failed.", the local storage is automatically bypassed
  and invalidated, triggering a fresh, self-healing pipeline run on the backend.
