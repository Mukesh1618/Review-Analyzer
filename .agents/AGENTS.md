# Review-Analyzer Agent Rules

## Communication and Execution Guidelines
- **Answer First:** When the user asks a question, answer it directly. Do not start executing tasks or modifying code automatically.
- **Analyze and Plan First:** When given a new task, always analyze the requirements, research the codebase, and create an `implementation_plan.md` (or provide a written plan) for the user to review. Do not start coding or executing until the user explicitly approves the plan.
